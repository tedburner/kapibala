# Spec Delta

## Purpose

为桌面会话输入提供斜杠命令面：`/` 前缀输入走与 CLI 同源的命令系统而不是发给模型，命令补全与执行结果在会话界面可见。命令语义与 CLI 完全一致，不产生第二套命令实现。

## ADDED Requirements

### Requirement: 斜杠前缀识别与命令补全

会话输入框中，以 `/` 开头的输入 MUST 触发命令补全面板（命令名 + 用法摘要），补全列表 MUST 与可用命令目录一致；未匹配任何命令的 `/` 输入提交时 MUST 按命令路径处理并回显「未知命令」类反馈，MUST NOT 被当作普通消息发给模型。不以 `/` 开头的输入行为不变。

#### Scenario: 补全列表与命令目录一致

- **WHEN** 在输入框键入 `/s`
- **THEN** 补全面板列出全部以 s 开头的可用命令（如 `/skills` `/skill` `/status`）及其用法摘要

#### Scenario: 未知命令不发模型

- **WHEN** 提交 `/nosuchcmd`
- **THEN** 会话界面回显未知命令反馈，不产生模型请求、不计费、历史不新增用户消息轮次

### Requirement: 命令执行与 CLI 同源

`/` 命令 MUST 经与 CLI 相同的命令分发器执行，命令行为（参数解析、权限门禁、输出内容、错误反馈）与 CLI 一致；命令输出 MUST 在会话界面可见（作为命令反馈消息，与模型消息有明确区分），MUST NOT 伪造模型回复。命令执行期间会话忙碌状态 MUST 正确反映，运行中会话的变更类命令与 CLI 一样被拒绝。

#### Scenario: 只读命令即时反馈

- **WHEN** 会话空闲时提交 `/status`
- **THEN** 会话界面展示与 CLI `/status` 一致的状态信息，会话历史不新增待模型处理的轮次

#### Scenario: 变更命令尊重忙碌门禁

- **WHEN** 会话正在执行模型任务时提交变更类命令（如 `/branch`）
- **THEN** 命令被拒绝并提示会话忙，与 CLI 的忙碌门禁行为一致

### Requirement: 技能直发命令

`/skill <名称> <任务>` MUST 触发显式技能执行（与 CLI 同语义）：走既有技能授权、审计与执行路径，执行事件以普通会话事件流呈现。技能名补全 MUST 可用且与技能目录一致。

#### Scenario: 技能直发走完整授权

- **WHEN** 提交 `/skill review 帮我评审这段代码`
- **THEN** 显式技能流程启动（授权裁决、技能正文附加、事件流渲染），与 CLI `/skill` 行为一致

### Requirement: 交互命令的对话框映射

需要用户应答的命令交互（选择列表、问答、密钥输入）MUST 通过桌面对话框完成：请求以会话级交互事件呈现，应答经受控通道返回，超时/关闭按取消处理；密钥输入 MUST 走脱敏输入框且不留痕于消息历史。首版未接入对话框映射的交互命令 MUST 在被调用时明确提示暂不可用，MUST NOT 卡死输入通道。

#### Scenario: 选择类命令映射对话框

- **WHEN** 执行需要选择的命令且选择对话框映射已接入
- **THEN** 会话界面弹出选择对话框，用户选择后命令继续；关闭对话框按取消处理，不产生半完成状态

#### Scenario: 密钥输入不落历史

- **WHEN** 执行需要密钥输入的命令
- **THEN** 输入框脱敏展示，输入值不出现在会话历史与日志中

### Requirement: 命令权限语义不变

命令面 MUST NOT 改变 CLI 命令的既有权限与审计语义；命令执行产生的副作用（设置变更、会话分支等）与 CLI 执行完全一致，且在桌面会话上下文中正确作用于当前托管会话而非全局隐式状态。

#### Scenario: 命令作用于当前会话

- **WHEN** 在已打开的会话中执行 `/branch`
- **THEN** 分支作用于该托管会话（与 CLI 在同会话执行 `/branch` 等效），不隐式切换其他会话
