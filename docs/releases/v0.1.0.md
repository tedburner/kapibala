# Kapibala v0.1.0：桌面客户端（发布候选草稿）

尚未发布；签名、公证、跨平台安装及最终 SHA 的全部发布证据完成后，才能将本文改为实际发布说明。当前本地版本仍为 0.0.10。

Core/CLI/MCP 继续独立分发，协议保持 wire 1.0。桌面安装器与三份 npm 包分别验证，正式 Release 复用经审核的同一批候选附件。
