# Kapibala v0.0.8：产品化终端体验、纯展示模型与命令解耦

本版完成终端底层守护（ConPTY/CSI-u/Bracketed Paste 安全输入与异常自愈）、跨端纯展示模型（`@kiturone/kapibala-cli/view-model` 子路径导出，浏览器级 0 Node 依赖）、宿主桥接中枢与命令结构化输出解耦（CommandOutput），为后续桌面端与全屏交互奠定统一状态底座。本地与集成验收见 [验收记录](../verification/v0.0.8.md)，迁移指南见 [迁移说明](../migration/v0.0.8.md)；「本版明确未交付」一节列出与发布口径绑定的排除项。

## 交付要点与新增能力

- **终端底层基础设施与输入守护**：
  - 引入 `TerminalModeGuard`：双重异常兜底（`uncaughtException` / `unhandledRejection`）与进程退出钩子，退出时确定性恢复光标（`\x1b[?25h`）、退出备用屏（`\x1b[?1049l`）、关闭 Bracketed Paste 模式（`\x1b[?2004l`）并恢复 TTY rawMode，杜绝终端假死或控制序列污染宿主终端；
  - 引入 `TerminalInputFramer`：化解 Windows ConPTY 与网络传输带来的 CSI-u 按键分片问题（40ms 拼包缓冲）；隔离 Bracketed Paste 粘贴块，禁止大段粘贴内容在未确认时意外触发快捷键或执行命令，并设置 1MiB 粘贴上限防止内存 DoS；
  - 引入 `TerminalInputStream`：单读者管道流保证输入消费唯一性，防止多组件争抢 stdin；
  - 引入 `TerminalEditor`：基于 `Intl.Segmenter`（Unicode Grapheme Cluster）的跨平台多行终端文本编辑器，正确度量中文宽字符、组合字符（如 `e\u0301`）与 ANSI 样式，提供行内光标移动、历史翻阅与安全编辑。
- **跨端纯展示模型（`@kiturone/kapibala-cli/view-model`）**：
  - 将终端与未来 GUI 共享的前端展示状态抽取为无副作用纯展示模型（`TerminalViewModel`、`terminalViewReducer`）；
  - 纯函数 Reducer 消费 Session / Host / UI 事件，管理消息流式追加、思考折叠、命令目录（聚合 Slash 命令、Skills、MCP Prompts，支持模糊搜索与键盘导航）、底部状态条（SessionFacts / TaskObservation）与视窗虚拟滚动（Virtual Scroll）；
  - 引入快照级 Memoization（`selectMessages` 基于 WeakMap 对快照进行缓存），高频流式渲染时不重复全量遍历；
  - 提供独立浏览器级构建产物与 0 Node 内置依赖边界：新增 `packages/cli/tsconfig.view-model.json` 与 `tsup.view-model.config.ts`，由 `scripts/check-view-model.ts` 门禁保证 100% 浏览器/DOM 运行环境兼容，供未来桌面端（Electron / Web）直接复用。
- **宿主桥接中枢与命令输出解耦**：
  - 引入 `SessionPresentationHost` 与 `PresentationStore`：订阅 `AgentSession` 事件，按 16ms 防抖批量向 View Model 发送 `AGENT_EVENT`，支持暂停/恢复与安全取消；
  - 全量解耦所有内置命令输出：彻底消除 `packages/cli/src/commands/` 下所有 20+ 个内置 Slash 命令（`/help`, `/status`, `/mcp`, `/model`, `/branch` 等）中直接写屏的 `console.log` / `process.stdout.write` 隐式副作用，统一返回结构化 `CommandOutput`（Markdown、标题、元数据等），由宿主在适当位置（Inline / View Model / 降级流）统一渲染；
  - 引入 `scripts/check-cli-boundary.ts` 架构门禁，静态扫描拦截 `packages/cli/src/commands/` 下直接写屏行为，杜绝终端重叠与布局撕裂。
- **多任务状态与观察（TaskObservation）**：
  - Core 在 `AgentRuntime` 中新增 `subscribeTaskChanges` 观察订阅接口，在子代理创建、状态变更（preparing → running → completed/failed）时触发只读通知；
  - CLI 宿主 `TaskObservationHost` 无侵入订阅子任务变化，实时聚合反映在展示模型状态栏中，支持多子任务树观测与并行活动计数。

## 本版明确未交付

以下能力在本版**不生效**或排入后续版本，避免「接口存在、语义空转」：

- 全屏 Ink TUI 主视图切换（阶段 D）：本版重点完成底层终端守护、展示中枢与命令解耦，全屏交互与命令面板键盘直选平滑过渡至下一版；
- Electron 桌面客户端包（`packages/desktop`）：已确立 `@kiturone/kapibala-cli/view-model` 为其通用前端状态基石，桌面包按路线图排入 v0.1.1；
- Git Worktree 物理隔离与子代理审批冒泡队列：继续按原排期在后续版本推进。

## 安装与使用

需要 Node.js 20 或更高版本。

```bash
# 全局安装 CLI
npm install -g @kiturone/kapibala-cli

# 安装 Core SDK 与 MCP 扩展包
npm install @kiturone/kapibala @kiturone/kapibala-mcp
```
