# Kapibala v0.0.7：会话增强、因果分支与多智能体运行时

本版实现多工作区并发隔离、Schema v2 因果日志与会话分支投影，并引入后台多智能体运行时（AgentRuntime & Subagents），保持 Headless Core 运行时零外部依赖。本地与集成验收见 [验收记录](../verification/v0.0.7.md)，迁移指南见 [迁移说明](../migration/v0.0.7.md)；「本版明确未交付」一节列出与发布口径绑定的排除项。

## 交付要点与新增能力

- **显式工作区身份与沙箱安全防线**：
  - 彻底移除 Core 内部对全局 `process.cwd()` 的隐式依赖，`AgentSession` 强制要求显式传入 `workspaceRoot` 绝对路径（缺少抛出 `WORKSPACE_ROOT_REQUIRED`）；
  - `PathSandbox` 重构为会话持有实例，废除全局单例缓存；
  - 统一 Windows 路径规范化为 `fs.realpathSync.native`，杜绝短文件名与大小写失配；
  - 引入 `WorkspaceLeaseCoordinator`（进程内单例 `sharedWorkspaceLeaseCoordinator`）提供细粒度工作区写租约互斥，保障任务异常或取消时可靠释放。
- **Schema v2 因果日志与平滑升级**：
  - 升级为 Schema v2 Envelope 日志格式，分离物理严格时序（`seq`/`prevRecordId`）与因果追溯链（`parentId`/`branchId`），支持全局控制记录（`parentId: null`）；
  - 解耦三大版本号（`logRevision`、`branchLeafId`、`contentRevision`），支持增量 sidecar 校验；
  - 存量 Schema v1 日志支持严格只读回放；写入或续答自动创建 `_v2` 升级副本（Header 记录 `upgradeIdentity` 以幂等复用），原 v1 历史绝对不被破坏。
- **持久因果分支与会话投影**：
  - 支持持久分支切换（`selectBranch`）与分叉（`createBranch`），`/branch create` 以记录 id 为切点并原子切换活动分支；
  - `buildProjection` 沿因果链（`parentId`）提取当前分支的合法线性视图，严格拦截未闭合工具事务的分叉（`UNCLOSED_TOOL_TRANSACTION_FORK`），并识别崩溃恢复写入的 `history_repair` 叠加记录（修复过的会话仍可正常分叉）；
  - 拒绝以全局控制记录（标题、用量等 `parentId: null`）作为分叉切点，避免产生空历史孤儿分支；
  - 支持将会话活动分支导出为独立全新会话（`forkSession`），状态隔离且不继承源会话累计费用。
- **后台多智能体运行时（AgentRuntime & Subagents）**：
  - 内置四大管理工具：`spawn_agent`、`list_agents`、`wait_agent`、`cancel_agent`（声明 `agent:spawn` 权限）；
  - 完整状态机生命周期：`preparing` → `accepted` → `running` → `waiting_children` → `completed`；
  - 启动事务即刻闭合：父代理调用 `spawn_agent` 受理即刻闭合父工具事务，无需同步阻塞；
  - 终态通知耐久化：`SubagentOutbox` 以追加日志保存终态通知与 ACK，进程重启后仍可读回未确认通知；`SessionInbox` 按 `eventId` 幂等去重后写入父会话历史；
  - 投递为显式拉取：由 `/agents collect <id>` 把通知注入来源分支，异分支来源直接拒绝并给出切换提示；空闲时自动唤醒投递尚未接入 REPL。
- **层级安全限额与权限求交**：
  - `deriveChildPolicy` 以父会话**真实**模式、权限规则与可用工具表为输入，在工具、文件、执行、网络与预算上逐轴求交，子代理权限只减不增；
  - 内置 `explore`、`planner`、`implement`、`advisor` 角色预设与场景模型路由；Plan 模式硬拦截 `agent:spawn`；
  - 严格限额与深度熔断：最大深度 3、活动槽位 4、运行时 8、累计 16、步数 15、超时 5 分钟；达到最大深度自动剥夺派生工具权限；
  - 子会话持有独立 Store 与收紧后的工具表；未继承父终端审批通道，`Approval` 模式下无通道的敏感工具按 `deny_once` 保守拒绝（审批冒泡到父终端排入 v0.0.8）。
- **Worktree 物理隔离（本版未交付）**：
  - `spawn_agent` 的 `isolation: 'worktree'` 在受理前显式拒绝（`CONFIG_INVALID`，「当前环境暂不支持 worktree 物理隔离模式」），仅 `inherit` 生效；
  - 未提供 Git Worktree 独立执行目录，脏基线检查与安全回收随 v0.0.8 排期。
- **跨项目全文检索与逻辑归档**：
  - `CrossProjectSessionCatalog` 流式扫描跨项目全局会话；
  - 支持分词、短语、字段限定与有界正则 worker 超时熔断检索；
  - 逻辑归档（`archive_state`）与恢复，运行中会话硬拦截归档。
- **CLI 交互与命令扩展**：
  - `/history` 支持 `--tree`（分支因果树）、`--search <query>`（全文搜索）、`--all [page]`（全局会话漫游）、`--agents`（子任务树）；
  - 新增 `/branch`、`/fork`、`/archive`、`/agents` 管理命令；
  - 终端底栏紧凑展示子代理状态行，`Ctrl+O` 展开详情；在秘密输入期间自动缓冲后台异步输出。

## 本版明确未交付

以下能力在本版**不生效**，`isolation: 'worktree'` 之外的相关组件已从代码中移除（避免「接口存在、语义空转」），统一排入 v0.0.8：

- Git Worktree 物理独立执行目录与脏基线回收；
- 后台通知的空闲自动唤醒投递：REPL 不轮询发件箱，子代理终态只由 `/agents collect <id>` 显式注入父历史；
- 子代理危险工具审批冒泡至父终端交互队列：子会话无审批通道时按 `deny_once` 保守拒绝；
- 任务树 Token 分层账本（`ownUsage` / `descendantUsage` / `summaryUsage` 聚合与预算校验）：跨层级归集未实现，仅保留单会话自身的用量与摘要用量分账；
- 跨分支共同祖先摘要注入（`branchWithSummary`）：`branch_summary` 记录类型与全文检索读取面保留，本版无写入方。

## 安装与使用

需要 Node.js 20 或更高版本。

```bash
# 全局安装 CLI
npm install -g @kiturone/kapibala-cli

# 安装 Core SDK 与 MCP 扩展包
npm install @kiturone/kapibala @kiturone/kapibala-mcp
```
