# Kapibala v0.1.5：开放外部代理工作台、四套原生直连驱动与桌面交互打磨

感谢使用 Kapibala 并反馈体验建议。本版带来开放外部代理工作台、会话内动态切换外部模型与模式，以及一整轮桌面会话流与跨平台稳定性打磨。

## 外部代理一窗统管、动态切换模型模式、更清爽的会话流与 Windows 无 Shell 解包 ✨

- 🤝 **直连本机 Claude Code、Codex、Pi 与 ACP 编码代理。** 新增零外部 SDK 依赖的四套原生管道（`claude-cli`、`codex-app-server`、`pi-rpc` 与通用 `acp`），覆盖 13 项按本机安装状态自动启停的内置预设、7 项官方 ACP 模板与任意本地自定义 ACP 命令，直接复用各 CLI 自有订阅与登录态。
- 🎛️ **新建对话与空闲会话随时切换外部代理模型、模式与推理档位。** 在输入框统一搜索选择内置模型或外部代理模型，外部会话空闲时可直接在底栏或通过 `/external config` 动态切换模型、工作模式（如 `Code / Plan`）与推理档位，配置目录按配置指纹本地缓存，再次打开无需冷启等待。
- 🖥️ **设置页新增「外部代理」全图形化管理中心。** 在单层分割列表里一键启停预设、探测协议握手与版本号、复制终端登录或安装命令、配置可执行路径覆盖与 `envFrom` 环境变量名白名单，或在保存前直接对自定义 ACP 命令执行握手测试。
- 💬 **重构桌面会话流、侧栏布局与明暗双主题细节。** 对话正文升级为扁平工具流与轮次级过程自动折叠，等待授权时准确提示「等待审批确认」；侧栏隐藏空的临时对话区块，外部会话改为双行完整标题布局；修复暗色模式代码块对比度失效与开关滑块视觉反相问题。
- ⌨️ **已完成任务看板自动收起，继续会话即可上下键召回历史问句。** 任务清单全部完成后在下一轮新提问时自动收起，未完成项继续保留；重新打开本地或外部历史会话时，直接在输入框按 `↑/↓` 即可翻找此前发送过的提问并保留当前草稿。
- 💻 **CLI `/external` 全套命令与 Wire v2 `external-session` 扩展。** 终端新增 `/external` 命令组，与桌面端读写同一份 `~/.kapibala/external/` 配置与只读归档；本地宿主协议保持整数版本 `2` 不变，增量扩展 `external-session` 能力与 16 个 `external/*` 方法。
- 🛡️ **Windows 无 Shell 静态解包与有界只读归档保护。** 全程 `shell: false` 静态解包 `.exe`、受管 `node_modules` 脚本与同目录启动器（如 `pi.cmd`）三类垫片；每轮结算原子写入上限 160 条 / 680 KiB 的脱敏只读快照，子进程空闲回收或重启后历史对话立即可读，并按四项持久身份门禁与 `configDigest` 决定是否开放原地续聊。

## 详细变更

### 🤝 外部代理与驱动

*四套零外部 SDK 传输驱动上线，支持 13 项内置预设按安装态启停、会话内动态切换配置项、交互式人工审批与脱敏只读快照归档。*

* 新增 `claude-cli` 原生直连驱动：对接本机 `claude` 双向 `stream-json` 与 `stdio` 权限通道，支持流式思考与正文增量、`TodoWrite` 计划同步、`control_request(can_use_tool)` 交互审批、`interrupt` 取消与 `--resume` 恢复，并禁用无 TTY 下易挂死的交互提问工具
* 新增 `codex-app-server` 原生直连驱动：适配无 `jsonrpc` 字段的 JSON-RPC lite 帧，打通 `thread/start`、`thread/resume`、`turn/start`、`turn/interrupt`、`turn/plan/updated` 及命令执行与文件修改双向审批
* 新增 `pi-rpc` 原生直连驱动：对接 `pi --mode rpc` 并自动挂载宿主受管只读审批守卫扩展，将写文件与命令执行纳入统一人工审批卡（按工具粒度隔离会话放行），支持 `--session-id` 恢复与 `abort` 取消
* 新增通用 `acp` 驱动与轻量方言容错层：内置支持 Antigravity（`agy acp` 惰性按需协商认证，已登录免弹浏览器）、OpenCode（兼容 `session/load` 预绑路由与先行重放通知，自动读取本机默认模型偏好）、DeepSeek Harness（兼容 `sessionCapabilities.resume`）、Oh My Pi、Qoder / Qoder CN、TRAE / TRAE CN、Gemini CLI、Qwen Code 及 7 项官方 ACP 模板
* 内置预设改为按本机安装状态智能默认启停：仅当系统 `PATH` 或已知 GUI 安装目录检测到对应可执行文件时默认启用，未安装项默认停用
* 支持外部代理动态配置项（模型、模式、推理档位）探测、按配置指纹本地缓存，以及新建会话指定初始模型与空闲态热切配置
* 新增 `ExternalSessionService` 并发与生命周期编排：单宿主上限 4 个活跃外部进程、同工作区单运行互斥、30 分钟空闲自动回收、10 分钟无进展看门狗（等待人工审批期间自动暂停计时）与 120 秒审批超时收口
* 新增 `~/.kapibala/external/` 独立存储域（权限 `0700/0600`）：`harnesses.json` 独占锁增量覆写事务、`sessions.json` 最近 50 条会话登记（满额优先淘汰最早终态项）与 `snapshots/` 680 KiB 有界脱敏只读快照归档
* 修复 `setSessionConfig` 与 `prepareAndLaunchPrompt` 在校验工作区信任、目录归属及槽位忙闲状态前因 `configDigest` 漂移提前关闭活动槽位的竞态，并在 `setConfigOption` 异常后可靠恢复空闲回收计时器
* 修复跨宿主重复续聊冲突、取消强杀后的僵尸槽位残留、跨分片流式脱敏边界与原生会话 ID 前缀注入风险

### 🖥️ 桌面客户端与对话体验

*统一新对话模型与外部代理选择器，升级扁平对话流与内联审批体验，修复暗色代码高亮、开关滑块与历史问句召回问题。*

* 重构桌面会话消息流：采用扁平工具流与轮次级过程自动折叠，新增尾部实时状态行与续跑入口，任务进度胶囊居中展示；外部代理处于待审批态时状态行明确提示「等待审批确认」
* 统一新对话输入框的模型与外部代理搜索选择器（精简原侧栏独立新建弹窗），修复长模型名称在下拉项中的截断溢出
* 新增设置弹窗左栏「外部代理」标签页，采用 `780px` 宽幅单层分割列表呈现内置代理与自定义 ACP 表单，消除多层卡片套娃与命令预览过早截断
* 优化侧边栏会话列表：无临时会话时自动隐藏空占位分组；外部会话改为双行展示完整标题、代理名称与状态，操作菜单叠层定位不再挤压标题；本地会话悬停显示操作按钮时淡出尾部时间戳
* 优化外部会话主视图与内联审批卡：精简顶部重复的代理名称与静态徽标，为审批卡增加琥珀色强调边条与倒计时展示，并移除只读归档会话中无响应的消息编辑按钮
* 修复 Tailwind v4 `dark:` 变体未绑定 `[data-mode="dark"]` 导致暗色模式下 Shiki 代码块回退为深黑字色不可读的问题，同时将 `Switch` 统一改为 2px 内缩单色滑块，消除默认亮蓝色与暗色模式开关方向错觉
* 修复已完成任务清单在后续新轮次残留占屏的问题（未完成项仍跨轮次保留），并支持在重新打开或继续本地与外部历史会话时用 `↑/↓` 召回历史提问
* 修复前端快速切换外部会话配置或关闭会话时未按单调序号同步 `activeExternalRef` 导致的快照回退竞态
* 收敛三端窗口顶栏与菜单栏，修复 Windows 任务栏图标、预设模型厂商缺失、非默认项目空间 `@` 文件搜索、新对话 `/skill` 直发、发送卡顿与审批半开假死问题
* 后台外部会话完成、失败或进入待审批时，窗口失焦自动发送系统通知，前台弹出轻量提醒卡片

### ⌨️ CLI 与本地宿主协议

*新增 `/external` 对等管理与会话命令，Wire v2 非破坏性扩展 `external-session` 能力，补齐普通目录信任引导。*

* 新增 `/external` 命令组：支持 `list`、`harnesses`、`harness test|add|enable|disable|remove|reset`、`start [--model <id>]`、`config <sessionId> [model|mode|thought <值>]`、`show`、`prompt`、`approve`、`cancel`、`close`、`delete`，内置引号感知的非 Shell 参数分词以兼容带空格的 Windows 路径
* 本地宿主协议保持 `PROTOCOL_VERSION = 2` 不变，`SERVER_CAPABILITIES` 新增 `'external-session'`，新增 16 个 `external/*` 方法与 `external/event` 实时通知，更新冻结契约快照 `scripts/fixtures/protocol/v2/contract.json`

### 🛡️ 执行底座、Shell 与跨平台兼容

*加固 Windows 无 Shell `.cmd` 垫片解析与两段式进程树回收，优化 Shell、WSL 与文件检索性能。*

* 新增 `ExternalProcessSupervisor` 与 `NdjsonChannel`：全程 `shell: false, windowsHide: true`，拒绝相对路径命令；内置 `~/.local/bin`、`~/.pi/agent/bin`、npm/pnpm 全局目录及各厂商 CLI 默认路径只读兜底；按 `[".exe", ".cmd"]` 优先级探测并以 `fs.realpathSync.native` 静态解包标准 npm/pnpm 与官方安装器 `.cmd` 垫片（覆盖 `.exe`、受管 `node_modules` 脚本、同目录启动脚本如 `pi-launcher.js` 及 `#!...node` 无后缀脚本）

* 外部子进程环境白名单隔离：剥离相对 `PATH` 段、`NODE_OPTIONS`、`ELECTRON_RUN_AS_NODE` 与动态库预加载变量，仅透传基础运行环境与显式声明的 `envFrom` 变量名
* 内置 `grep` 工具新增可选 `include` 通配符过滤并修复单文件过滤路径，优化 `glob` 广度优先剪枝，开放受控工具自纠错诊断与 CRLF 编辑适配，默认会话最大步数上限上调至 `60`
* 调整 Windows 默认 Shell 探测优先级与 `wsl.exe --exec` 变量传递，加固 `PathSandbox` Windows `realpathSync.native` 物理路径归一与 Node 24 开发脚本锁自愈

## 升级与安装说明

本版为**非破坏性升级**：`@kiturone/kapibala`（Core）与 `@kiturone/kapibala-mcp` 公共导出零破坏性变更，本地宿主协议保持整数版本 `2`（未声明 `'external-session'` 的旧客户端仍可正常连接并使用全部本地会话能力）。升级细节与安全边界见 [v0.1.5 迁移说明](../migration/v0.1.5.md) 与 [SDK 兼容性盘点](../sdk-compatibility.md)。

- **命令行与 SDK（需 Node.js 20+）**：

```bash
npx @kiturone/kapibala-cli@0.1.5
npm install -g @kiturone/kapibala-cli@0.1.5
npm install @kiturone/kapibala@0.1.5
```

- **桌面客户端**：在下方 Release Assets 下载对应平台的安装包。当前桌面构建仍为未签名个人自用测试包，macOS 首次打开需右键打开或执行 `xattr -dr com.apple.quarantine`，Windows 首次运行会提示 SmartScreen；下载后请核对 `SHA256SUMS.txt`（详见 [桌面发布说明](../desktop-release.md)）。
- **权限边界提醒**：外部代理遵循各自 CLI 的权限与登录态，Kapibala 本地的 `Auto` / `FullAccess` 绝不会自动批准外部代理请求；同工作区多 Agent 并行所需的 Git Worktree 隔离将在 `v0.1.6` 提供。

**完整变更对比**：https://github.com/tedburner/kapibala/compare/v0.1.4...v0.1.5
