状态：阶段 A 实现及本地自动验收完成；不是 v0.1.0 发布或桌面 UI 交付证据。

范围：共享 Node `/host`、精确工作区身份、父子会话显式用户路径、有序展示与公共脱敏、可选历史读取预算、全局配置短事务和 CLI 写路径。设计真源为 [004](../design/004-v0.1.0-desktop-harness.md)。

## 回归范围

- exact 根在祖先 Git 仓库下保持独立，默认 git 规则不变，列表与恢复使用同一桶。
- 父子会话从显式 home 读取用户指令、写日志并恢复审计；不修改进程 cwd/HOME。
- 历史超限在恢复坏尾之前拒绝，原文件不变；读取过程增长、元数据、旧历史导入、v1 升级、显式重载共用预算；合法追加不被读取预算阻断。
- 超限重读失败保持原写者的活动分支和叶子，后续工具调用/结果仍接续原父链；扫描期间增长超限保留身份，不能由“继续最近历史”误建空会话。
- 事件不合并，重入保持观察者顺序，拒绝事件不发布，观察者异常与修改不影响其他观察者。
- 已知凭证跨增量脱敏，恢复历史与实时工具详情共享出口和调用身份；状态不暴露私有扩展字段。
- 配置重读保留其他写者字段；独立进程互斥、遗留锁不抢占、只释放本人锁；异常/异步回调/坏配置不覆盖文件；向导交互与探测期间其他写者可提交。
- 本地宿主延迟 MCP 授权、失败装配清理、清理失败保留锁；受管取消等待在途清理并拒绝重叠运行。
