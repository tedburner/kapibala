# v0.0.3 真实工具任务与压缩质量对比

日期：2026-09-27。三组指定任务已完成实际工具操作、真实摘要、重启恢复与原历史/压缩历史续答对比，并人工复核关键语义。该结果完成 OpenSpec 7.5 的小规模验收，不代表所有模型或真实项目均有相同质量。

执行器：`scripts/v0.0.3-live-quality-check.ts`；汇总证据：[v0.0.3-live-quality.json](v0.0.3-live-quality.json)。实验使用已配置 `deepseek-flash`，主请求窗口 64K、摘要窗口 32K，每轮最多 8 个内部步骤，每次压缩最多两次显式手动尝试。未更改用户配置或产品重试策略，凭据只在进程内解析，未写入证据。

## 实际结果与语义复核

| 场景 | 实际执行及恢复结果 | 压缩后的保留情况 |
|---|---|---|
| [多文件约束](v0.0.3-live-quality-multi-file-constraints.json) | 真实读取、局部修复加法并运行 Node 测试；摘要提交后重启，两条分支分别实现安全整数输入/结果校验和溢出测试；宿主独立检查负数与溢出行为 | 保留接口、修改范围、禁止改依赖/验证脚本和删除测试、已通过结论与溢出待办；两条分支均完成后续任务 |
| [长测试输出与未知写入](v0.0.3-live-quality-command-output-and-unknown-effect.json) | 命令实际输出 400 行进度及末尾负数断言错误；写入 `candidate` 后注入确认丢失，轮次按 OUTCOME_UNKNOWN 停止；下一轮修复并验证，再摘要、重启、续答 | 摘要保留末尾关键错误、成功修复和溢出待办；未知写入单独列入 unknownEffects 和 unknownFileOperations，未列为成功修改；用户明确核实后两条分支各读一次、检查一次，均得到 candidate，无重写 |
| [连续摘要与重启](v0.0.3-live-quality-rolling-summary-restart.json) | 真实实现分页和非法页码校验，追加测试与 notes 决策；连续提交两次滚动摘要，再重启并续答 | 保留接口、每页 20 项、起始页 1、非法页码 RangeError、缓存从正文重建、浏览不更新时间，以及唯一 ID 前缀歧义测试仍未完成；两条分支均只读 notes 一次、检查一次，无重复修改 |

三组重启均逐项比较恢复前后的请求投影和摘要 usage，且恢复本身没有调用 Provider 或工具。最近完整成功交互保持原文。第三级任务内部压缩未引入。

多文件续答原历史/压缩历史分别执行 **3/3 次读取、2/2 次编辑、1/1 次命令**；原历史重复读取同一源码，压缩分支额外读取验证脚本，不能据此声称压缩减少读取。另两组各分支均为 **1 次读取 + 1 次命令**，没有重放既有写入或修复。滚动样本在摘要前发生一次匹配失败的 edit，随后读取真实内容再成功编辑；失败记录保留，未计为成功文件修改。

语义复核也记录有限偏差：零用例在原实现中本来已通过，模型有时把根因描述成“负数/零错误”；模型提出的 NaN 等后续边界未作为新授权。两条分支的关键执行结论和约束仍一致，但这不是逐字一致或零幻觉保证。

## 验收发现与修复

- Windows 受限环境遗漏 PATHEXT，PowerShell 未正常等待/捕获绝对路径 Node 原生命令。补入环境白名单；真实回归同时断言 stdout、exitCode 和文件实际写入，环境仍参与执行指纹与审批。
- 旧失败轮次永久阻断二级摘要。现在允许保护范围外、有终态来源且工具事务闭合的失败/中断旧轮次参与摘要；不推断成功，不重放工具，缺结果或缺终态证据仍保留。第一级剪裁继续仅限成功完成旧轮次的成功读取/搜索。
- 验收脚本最初拒绝合法的隔离文件绝对路径与有限输出显示后缀，且把预期的未知结果停止当成未完成。现按临时项目内白名单核对路径、有限命令列表和预期终态；未修改产品授权裁决。

全部产品修复经过失败测试复现及回归验证。小样本通过与本地构建通过不构成 GitHub/npm 发布。
