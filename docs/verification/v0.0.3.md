## Windows / POSIX 真实进程

`scripts/v0.0.3-platform-check.mjs` 在 Windows 与 WSL/Linux 的 Node v24.18.1 上均通过以下八项：

1. 两个子进程竞争仅一个写者。
2. 确认原进程退出后恢复旧锁。
3. 写入 assistant 后异常退出，恢复持久缺失结果修复。
4. 恢复不重放工具或创建未知写入文件。
5. 在途模型迭代 return 触发中止。
6. 清理完成前保持 busy 与写锁。
7. 检查点提交前强制终止进程，恢复原投影。
8. 检查点 fsync 后、内存激活前强制终止进程，恢复已提交投影与单份使用量。

Windows：`node scripts/v0.0.3-platform-check.mjs`。POSIX：在 Linux 用 Node 执行同一脚本并传入 Core 构建产物的绝对路径。WSL 启动时产生宿主代理提示，脚本未请求网络，八项结果通过；此次未把 Linux 定向平台验收写成 Linux 全套 `pnpm verify`。
