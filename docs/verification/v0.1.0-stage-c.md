# v0.1.0 阶段 C：完整会话体验本地验收

实施：2026-10-24；收口：2026-10-25。范围为 [004 设计 C1–C4](../design/004-v0.1.0-desktop-harness.md#阶段-c完整会话体验)。基于阶段 A/B 工作区继续实施，包版本保持 0.0.10，未提交、未发布。以下为 macOS 开发构建证据，C4 的 Windows/Linux 托盘、系统通知送达及系统设置操作仍 pending；不代表安装、签名或正式发布通过。

## 实现与实际交互

- 空间与会话分组、默认置顶、同名项目独立身份、50 项历史分页、句柄菜单；空闲关闭、运行中停止并关闭、清理失败重试。草稿与滚动按空间/历史身份保存在 Renderer 内存，不通过关闭详情释放运行时。
- 独立运行摘要至多 8 项，不包含正文；每订阅只暂存一份最新完整快照，revision 允许跳号。摘要/诊断走数据通道，不侵占停止信令队列。失效后保持未知，旧通知或初始读取不能恢复信任。
- Markdown/GFM、思考折叠、离线代码高亮与复制，千条历史虚拟列表；向上阅读停止跟随，返回底部恢复。HTML 不执行，远程图片不自动加载。仅主页面获准剪贴板写入，不开放读取。
- 360px 工具/会话状态抽屉，1200 宽及以上并排，继续点击/Tab 输入保持打开；1199 及以下覆盖、遮罩关闭与焦点约束。工具行卸载后焦点返回消息区。关闭详情不取消工具，不影响独立审批队列。
- 模型角色与模式更新读取 Host 返回的实际配置；真实指标、Skill/MCP 已知状态及直接子任务观察。打开诊断不启动 MCP、不收集任务；Provider 缺失 usage 显示未提供，真实零用量保留。
- Main 后台完成/审批通知只显示通用文字，点击仅恢复窗口；关闭句柄、审批过期和控制期切换使旧点击失效。通知不承载参数、路径或正文，也不执行审批。macOS Dock、Windows 托盘隐藏及显式清理退出；Linux 尝试创建托盘，但始终保留关窗退出确认，避免把 Tray 对象创建成功等同于系统入口可见。
- About 展示实际包版本、Electron/Node/Chromium 版本和原生支持状态；复制诊断只包含这些白名单字段。主题 light/dark/system 与首帧恢复，减少动效将库默认动画/过渡时长归零；源码门禁与依赖实现分开。

## 压力、失效与回归

- 8 个句柄允许打开，第 9 个拒绝；4 个并行运行，第 5 个拒绝。关闭后释放槽位，不自动驱逐。清理失败后禁止运行、配置及重新打开，保留显式重试入口。
- 摘要数据 ACK 挂起时仍可查询/取消运行，30 次展示重同步不重复运行；6 MiB 中文/emoji 快照继续遵循 4 MiB 窗口与逐块 ACK。继承阶段 B 普通 RPC 满额时仍可发送停止的测试。
- 审批完整绑定空间、会话、运行与审批 ID；切换空间不丢请求，旧控制断开默认拒绝；旧订阅、迟到安装确认、失效后的旧摘要/诊断回复不会恢复发送或可信状态。
- 最新快照合并、缺失 usage、清理失败复用、过期通知点击、焦点回退、剪贴板拒绝与深色按钮边界问题均有复现/回归；失败及通过日志保留在本次本地工作目录。

## 独立终审与修复

单次独立只读终审发现 1 个 Important 和 2 个 Minor，未发现 Critical。按用户实际影响，将历史分页被后台刷新打断从 Minor 提升为需要修复：

- 旧 `presentation.installed` Promise 在切换或重同步后迟到拒绝，曾错误冻结新视图。异常分支现同样核对 scope 与 installation；补充切换、重同步以及当前失败仍须冻结的回归。
- 历史刷新现保留空间页码，仅安装最新请求；迟到第一页回复不能覆盖第二页。真实窗口增加 51 份历史元数据，长对话在第二页，打开、后台刷新和切换后仍保留该页。

`review-red.log` 为失败复现，`review-green.log` 为通过结果；修复后桌面 34 单测与 4 个真实 Electron E2E 再次通过。终审未独立执行全套测试、平台 GUI、签名或长跑，这些结果来自本节明确列出的本地命令，不扩大审查结论。

**待优化 Minor：** Renderer 控制断开至重新连接之间，旧完成通知可能仍唤回已失效窗口。点击仅显示/聚焦窗口，不批准、执行或重放任务；新控制建立时撤销旧身份。后续应在 detach 开始时立即撤销通知，并补真实关闭路径回归。
