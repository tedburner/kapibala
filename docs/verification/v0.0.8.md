## 代码评审整改记录

本版实现先后经过终端经验方案评审与对抗性 Code Review，各项问题均已完成闭环收口：

| 评审问题 | 处置 | 证据 |
| --- | --- | --- |
| 1. `selectMessages` 高频遍历与性能开销 | 引入 WeakMap 实例级快照缓存，在视图模型状态引用不变时直接返回已计算的消息投影 | `view-model.test.ts`、`reducer.ts` |
| 2. `check-cli-boundary` Windows 路径大小写兼容 | 路径包含与排除逻辑统一采用 `path.resolve` 与大小写归一化（Windows 下统一小写后做 `startsWith` 比较） | `check-cli-boundary.ts`、`cli-boundary.test.ts` |
| 3. ConPTY 与网络抖动下的 CSI-u 分片拼包 | `TerminalInputFramer` 引入 40ms 拼包缓冲，完美拼合被操作系统切割的 Escape 序列 | `tui-input-framer.test.ts`、`v0.0.8-pty-check.py` |
| 4. Bracketed Paste 安全防线 | 拦截大段粘贴中的换行与控制字符，避免粘贴即执行；配置 1MiB 上限杜绝内存 DoS | `tui-input-framer.test.ts` |
| 5. 异常退出时终端假死 | `TerminalModeGuard` 监听未捕获异常、未处理拒绝与正常退出，确定性恢复光标、关闭备用屏与恢复 TTY rawMode | `tui-terminal.test.ts`、`v0.0.8-pty-check.py` |
