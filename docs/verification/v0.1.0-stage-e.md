## 两项已知问题

`ControlLifetime` 对本控制期的每次 Host 等待同时复核 Renderer 与 Backend，覆盖初次空间回复和二次别名恢复。失效回复拒绝继续更新最近项目、guard 或 registry；真实偏好文件回归先失败后通过。控制关闭在等待 Host detach 前立即重置 NativeNotices，原通知点击不能再聚焦失效窗口。三项回归 RED→GREEN，原两项 Minor 已处理。
