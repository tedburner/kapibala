# v0.1.0 阶段 B：桌面最小闭环验收

日期：2026-10-24。范围为 [004 设计 B1–B5](../design/004-v0.1.0-desktop-harness.md#阶段-b可用的桌面最小闭环)。这是 macOS 本地开发构建验证，源码仍在工作区，版本保持 0.0.10；不代表 v0.1.0 已发布、已签名或完成 Windows 安装验收。

## 已实现

- Main、单文件 CJS Preload、Renderer 与 utility Host 四入口；隔离、固定来源、导航/权限限制、异常 guard 和正常退出握手。Core 保持 Headless，Main 不装配模型或解析原历史。
- 默认空间逐层创建与重定向拒绝，原生项目选择、精确根信任、同根历史分桶。默认空间不向祖先 Git 提升；拒绝信任不应用项目配置或启动项目工具。
- Kumo/Tailwind 两栏对话、260/57 侧栏、800 最小窗口、建会话与续答、流式正文、紧凑工具状态、思考折叠、集中审批、当前模型/模式和全局设置。
- 全局模型预览确认：实际环境端点、分组和凭证来源；明确复用、新密钥或免鉴权，提示同组替换影响。64 个随机令牌、30 秒有效期，绑定当前控制对象、工作区、草稿、实际端点、相关凭证及项目覆盖。
- UTF-8 预算、1 MiB 帧、8 MiB 快照、256 KiB 分块、4 MiB 数据窗口与独立 64 KiB 控制窗口；逐块接收 ACK 和完整安装确认分离。64 个在途请求为控制保留 16 槽；等待业务完成不占住通道接收链。
- 操作去重、旧代次/旧订阅隔离、显式重同步；失效视图禁用发送，发送超时不重发。取消、审批、状态查询和关闭使用独立控制容量。断开先拒绝审批，再等待运行、在途装配与资源清理；失败保留所有权并支持显式重试。
- 首帧主题读取 Main 内存枚举，深色保存后 reload 保持深色；开发脚本在共享源码变化时等待正常退出再重建，不强杀 Host。

E2E 使用独立临时 homeDirectory、userData、项目目录和仅含必要系统字段的环境；Provider 为 loopback HTTP 确定性 SSE 服务，执行真实 Agent Harness 与 `write_file`，没有付费模型调用。原生目录选择仅替换系统选择器返回值，后续 Main 登记、信任、Host、存储、工具、IPC 和 Renderer 均运行真实实现。

1. 默认空间：祖先为 Git 仓库，确认精确默认根；新建、发送、审批真实写文件、取消挂起流、关闭后恢复历史。
2. 项目空间：拒绝信任后不创建项目配置；再次显式信任，审批写入项目根并恢复该空间历史。审批未处理时 reload，旧控制清理并拒绝请求，目标文件不产生。
3. 配置与主题：旧密钥不回显；预览确认前文件不变，明确复用后字段落盘，保存不产生模型请求；浅/深色切换及 reload；800 窗口侧栏收起且无页面水平溢出。
4. 默认目录文件占位：保持原内容、禁止建会话，可重新选择项目；不回退到 home。
5. utility Host 真实异常终止：保留 guard、状态未知；重启应用不 fork 新 Host、不重放，退出仍保留异常记录。

## 终审与回归

独立只读终审覆盖 B 阶段源码、脚本和共享宿主增量。修复并新增了以下回归：

- 项目专有密钥从侧栏历史标题脱敏，合并全局与当前项目已知凭证。
- 按目标 ID 独立检查另存，阻止借 `editId` 将已有内联密钥转移至新端点；新 ID 预览不带旧端点内联凭证。
- 实际环境端点与项目覆盖变化使预览冲突；设置先显示确认，再进行字段事务。
- 普通 RPC 满额仍可发送停止；等待一个会话清理时可查询另一个会话状态。
- 订阅身份不混用，失效时丢弃暂存；迟到安装确认不能恢复发送。6 MiB 中文/emoji 快照穿过 4 MiB 窗口，持续释放接收额度。
- Renderer 断开等待在途装配释放；清理失败保留句柄，utility Host 不永久缓存 rejected 清理承诺，显式退出可重试。

`project-key-red.log`、`snapshot-red.log`、`rpc-red.log` 和 `cleanup-red.log` 保留失败复现；相应通过结果见桌面单测与最终门禁。单测的 fake 资源只证明状态机，不代替真实 Electron/工具、平台进程树或安装后验收。
