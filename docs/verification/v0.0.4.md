## Responses 已观察行为

| 行为 | 结果 |
| --- | --- |
| 请求构造 | `/responses`、store:false、手动 input、无 previous_response_id、strict:false 保留可选 schema、max_output_tokens 包含总输出，推理模式不发送 temperature |
| Item 保真 | 多个 message 的 phase、内容分组、源 Item ID 与业务 call_id、原始参数串、空 message/空文本部分均可回传 |
| 工具事务 | 多个函数及 canonical tool 结果使用 call_id 闭合；源 Item ID 不用于匹配执行结果 |
| 私有状态 | 匹配 run/Profile/模型/端点的工具续答回传受控 reasoning，跨 run/模型剔除；最终答复后的独立提问不复用密文，原历史保持 |
| 展示 | 密文不输出 thinking_delta；明确可见摘要有块边界，拒绝作为文本及 refusal 标记展示 |
| 完成安全 | incomplete/failed/error/缺终态、坏参数/数组、重复身份、未完成 Item、hosted tool、只有 commentary、拒绝混合工具均失败且不产生可执行完成 |
| 流一致性 | 文本 delta/done/最终 Item、参数身份与内容需一致；不支持内容 part 明确失败；非关键元数据和 JSON 键顺序差异不误报 |
| 统计 | input/output/total/缓存 usage 正确映射；非法 usage 不先产生工具完成；缺失 usage 保持未知 |
| 传输 | 消费者提前退出等待 reader 清理；读取中 caller abort 保持联动；completed 后及时取消 reader，无需服务端关闭连接；socket 错误仅保留安全码 |

以上是协议模拟与本地确定性行为。真实服务可能存在模型权限、服务端参数、限流、计费和网络差异，本轮没有相关外部证据。

## 真实 API 与发布限制

Anthropic/OpenAI 原生工具冒烟：**未验证**。本轮没有已批准的调用费用预算，未发起真实付费请求。未验证账号权限、原生模型实际质量、真实缓存/成本及端点稳定性。

后续若获授权，可限制调用数和费用后分别执行原生问答、多工具续答、思考私有状态回传及跨协议会话。记录实际模型/端点、工具结果、终态、usage 和费用未知项，继续排除密钥、签名与密文正文。小样本结果不推广为通用质量保证。真实冒烟必须优先覆盖模拟测试无法验证的 wire 细节：官方 API 对 `x-api-key` + `Authorization: Bearer` 双头的接受度；`pause_turn` 在长回合中的实际出现与明确失败行为；Responses 对跨 run 回传 `msg_*`/`fc_*` item id、跨协议 `call_` 别名及 assistant `output_text` 历史的容忍度。

设计权衡记录：加密推理等私有状态当前仅限同 run、同模型、同端点的工具续答回传，比 pi（同模型跨 turn）、codex（全量回传 + 服务端 `reasoning.context` 控制采纳范围）、opencode（同模型）更保守。代价是跨 run 后历史中的 `provider_state` 块不参与回传，可能轻微损失推理连贯性与提示缓存命中；收益是回传面最小、不依赖服务端对跨请求状态的处理策略。是否放宽到同模型+同端点跨 run 需要单独的设计决策与费用评估，本版保持不变。

当前未进行版本更新、提交、合并、标签或推送。正式发布仍需用户审核、独立 Git 授权和项目 release 流程；版本号保持 0.0.3 到发布阶段。[迁移说明](../migration/v0.0.4.md)、[发布说明草稿](../releases/v0.0.4.md)、[场景路由](../models/scenario-routing.md) 与 [OpenSpec 任务](../../openspec/changes/v0-0-4-multi-protocol-routing/tasks.md) 已同步本次实现边界。
