## 三协议与安全边界集成

- **多协议适配**：在 `packages/mcp/tests/` 体系中，真实 Provider 适配器分别针对 Anthropic Messages、OpenAI Responses 和 Chat Completions 进行了工具事务闭合、原生受保护前缀（`thought_signature` / 不透明 Responses 状态）与取消状态回归，断言来源元数据不向 wire 泄露。
- **网络与传输防御**：Streamable HTTP 针对显式回环、RFC 1918 私网网段、CGNAT、链路本地、组播及保留地址实施了全量拦截，白名单解析通过底层 Socket Remote IP 二次复核抵御 DNS Rebinding；重定向时隔离鉴权凭据。
- **历史恢复不变量**：旧历史（无 `mcpSource`）加载兼容；新会话历史仅保留事实，恢复会话与切换项目绝不隐式继承服务启动权限或工具调用授权。

## 独立打包冒烟与真实进程回归

### 1. 独立 tarball 安装冒烟 (`scripts/v0.0.6-pack-smoke.ts`)

- 自动化执行 `pnpm pack` 分别构建 Core、MCP 与 CLI 三包的真实 tarball；
- 校验文件清单严格限定在 `dist/*`、`package.json`、`README.md`、`LICENSE`，无任何未编译源码或内部开发配置；
- 校验依赖约束：Core 运行时依赖为 0，MCP 精确依赖 Core，CLI 精确依赖 Core 与 MCP；
- 在隔离临时目录通过真实 `npm install` 安装三包产物，验证 CLI 版本与帮助（包含 `--no-mcp`），验证 Core 与 MCP SDK 在 ESM `import` 与 CJS `require` 环境下均可正确导出与运行。
- 清单校验改为在 pack 目录内以相对文件名调用 `tar`：含盘符的绝对路径会被 Git Bash 的 GNU tar 解析成远程主机（`Cannot connect to C: resolve failed`），导致该冒烟在 PowerShell（System32 bsdtar）通过、在 Git Bash 失败。修复后两种 shell 均实测通过。

### 2. 真实 CLI 进程回归 (`scripts/v0.0.6-platform-check.mjs`)

- 在隔离工作区启动真实 node CLI 进程并对接本地确定性 Mock 模型服务；
- 验证 `--no-mcp` 宿主开关：即使存在配置，CLI 绝不暴露任何 MCP 工具；
- 验证未信任项目隔离：未信任项目目录下的 `mcp.json` 被排除并输出安全告警；
- 验证非交互硬防线：非 TTY 环境下，未授权的 Stdio 服务启动被直接拦截（`TOOL_NOT_FOUND`），绝不静默启动外部子进程；
- 验证敏感字段脱敏：即使模型在工具参数中传入包含 key/token/secret 等字段，终端统一脱敏为 `[REDACTED]`，绝不泄露明文凭据；
- 验证会话历史文件本地持久化且结构闭合。
