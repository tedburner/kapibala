# Agent 上下文与 Skills 精简复跑手册（模型升级巡检用）

> **定位**：每次主力基座模型升级后（如推理能力、默认工具规范、长程遵循度跃迁），旧版写给上一代模型的「手把手保姆路线」会退化为昂贵的每轮背景噪声。按本手册跑一遍，可在**不丢失任何硬约束与踩坑记忆**的前提下削掉无用上下文税。
>
> **铁律优先级**：**守住不可逆与静默坑约束 > 放对加载层级 > 压缩字数**。确认清单前严禁改任何文件。

---

## 一、六步闭环标准流程

### Step 1 · 盘点每轮必载 vs 按需加载（算清上下文税）
- **统计单位**：同时记录字节数（防触碰宿主单文件截断线，如 Antigravity 的 `24,000 B`）与**上下文单元**（`中文字符数 + 非中文词数`）。
- **每轮必载面**：根 `AGENTS.md` / `CLAUDE.md`、跨端全局规则（`~/.claude/CLAUDE.md`、`~/.codex/AGENTS.md`、`~/.gemini/config/GEMINI.md`）、无 `paths:` 的 `.claude/rules/*.md`、持久记忆摘要（`MEMORY.md` / `memory_summary.md`）、所有已挂载 Skill 的 `description`。
- **按需加载面**：子目录嵌套 `AGENTS.md`、带 `paths:` 的 `.claude/rules/*.md`、各 Skill 的 `SKILL.md` 正文与 `references/`、`docs/` 专题文档。
- **真实调用审计（禁裸 grep 技能名）**：每个会话的系统提示词都会注入全量技能名列表，裸 grep 必假阳。必须解析历史会话的结构化事件（Claude `.claude/projects/*.jsonl` 的 `Skill` 工具、Codex `.codex/sessions/*.zst` 的显式 `$skill` 与定向读取、Antigravity `transcript.jsonl` 的 `tool_calls`、WorkBuddy `function_call`、Kapibala `load_skill`），并剔除单会话横扫 `>6` 个技能的安装/体检批次；新装未满 2 周的 0 调用标为「新装观察」，无会话记录的客户端标为「盲区」而非「未用」。

### Step 2 · 逐段五分类立账（确认前零改动）
每段原文按以下顺序裁决，生成 `文件:行号 | 规模 | 处置(修/删/挪/改写/保留) | 目的地 | 一句话原因` 账本交用户拍板：
1. **修（`fix`）**：已不存在的路径/命令/脚本、前后矛盾、未渲染模板占位符（如 `<!-- ... -->`）、缺失 YAML frontmatter、`.gitignore` 漏网项（如 `.claude/settings.local.json`）。
2. **删（`delete`）**：删掉后当前新模型行为**完全不变**的废话（如「先读代码再改」「记得跑测试」「注意边界条件」）、与 `docs/RELEASES.md` 或 `--help` 完全重复的流水账。
3. **挪（`move`）**：约束有效但放错了时机或作用域：
   - 跨项目不可逆红线 → 全局规则（经 `magpie library instructions` 同步全端）；
   - 需要上下文判断的可复用工作流 → Skill（多分支细则与大段示例进 `references/`）；
   - 子包/子目录专属不变量 → 子目录嵌套 `AGENTS.md`（或带 `paths:` 的规则）；
   - 仅特定场景使用的技能（如盯盘投研 vs 编码） → 在 Magpie 中收敛 `agents` 挂载范围；
   - 同样输入永远同样输出的校验/映射 → 门禁脚本（`scripts/check-*.ts`）或生命周期 Hook。
4. **改写（`edit`）**：
   - **写目标不写路线**：写清做完长什么样、怎么算完成（如 `pnpm verify` 全绿）、要什么证据；删掉可替代的中间步骤，仅保留**顺序本身就是约束**的规则（先验证再发布、先确认再删除）。
   - **名号 + NO/OK 替代口号**：把重复三遍的抽象要求压成一个词（如 `tight`、禁「复述腔」），配一组两行 `NO / OK` 示例。
   - **Skill 描述三要素**：`description` 只留「做什么 + 何时用 + 不用于什么」，所有口语同义触发词一律迁入 `when_to_use:`。
5. **保留（`keep`）——以下五类严禁删除**：
   - 用户个人偏好、明确否决过的方案及原因、本机/宿主环境事实；
   - **不报错的静默坑**（返回码 0 但结果为空/失真）与**看着像报错其实正常/误拦的现象**；
   - 描述句里的**半句否定约束**（「运行时 0 依赖」「不进 npm 发布集」「扫描全程只读」「不查真实连接值」）；
   - **单向门不可逆操作**（删数据、花钱、发版、提权、改写远端历史、提交推送授权）——**只准原样保留或整段原样搬迁，严禁压缩改写**；
   - 带日期的拍板决策锚点（如 `2026-11-16 起的约定`）。

### Step 3 · 先整行搬迁，再原地压缩
- 第一步只做**整行原样剪切粘贴**到按需文件，避免边搬边改导致约束静默蒸发。
- 搬进 `docs/` 的文档不会自动注入，必须在根 `AGENTS.md` 留一句明确的触发条件（「做 X 时必读 `docs/Y.md`」）。
- 根目录**不要新建 `CLAUDE.md`**（会导致 Claude Code 整仓关闭 `AGENTS.md` 及嵌套 `AGENTS.md` 链路）。
- 项目内重复全局规则的句子，只有在该项目使用的**每一个工具**都已配置并读取全局规则时才可删。

### Step 4 · 机械自检四件套
1. 所有 `paths:` glob 必须至少匹配到 1 个真实文件（`path_rules_matching_nothing == 0`）；
2. 检查各包 `package.json` 的 `"files"` 白名单，确认新增嵌套 `AGENTS.md` 或 `.agents/hooks` 不会误打入发布制品；
3. 全仓与全局技能库 grep 拆走或归档的旧文件名，确保零悬空引用；
4. 运行 `check_moved_lines.py <base-rev>`，每一条消失行都必须一对一落到已确认的 `删 / 改写` 清单行上，再跑通项目完整门禁（`pnpm verify`）。

### Step 5 · 独立盲审子代理防删过头
- 启动一个**未参与精简的全新只读子代理**，只给它「消失行列表 + 当前仓库」，**不给任何精简结论**。
- 让它从每条消失行提取**关键名词/标识符/日期/约束**全仓检索；凡是报出 `MISSING_MEANING`（语义无处留存）的条目，无条件从基准版本原样恢复。

### Step 6 · 埋暗号正反对照实测加载
- **不要轻信文档宣称的自动加载，必须实测**：在迁出的新规则文件末尾临时加一行唯一暗号（如 `SENTINEL-XXXX`）。
- 开两个干净新会话（禁止主动读/搜 `AGENTS.md`）：正向会话只读一个匹配目录的源码文件后问暗号（必须答出暗号），反向会话只读一个不匹配目录的文件后问暗号（必须答不出），测完立即擦除暗号。

## 二、本机多客户端实测避坑备忘

- **Antigravity 子目录 `AGENTS.md` 注入差异**：Antigravity 默认只从会话启动 `cwd` 向上寻址 `AGENTS.md`，调用 `read_file` 读子目录文件**不会**自动加载子目录 `AGENTS.md`；需配合 `.agents/hooks.json` 的 `PreInvocation` 钩子（见 [.agents/hooks/inject-nested-agents.mjs](../.agents/hooks/inject-nested-agents.mjs)）按工具访问路径动态一次性注入。
- **Windows `core.symlinks=false` 与仓库技能去重**：Windows 未开启 Git 符号链接时，`120000` 模式软链会检出为单行纯文本导致 Claude Code 无法识别技能目录，OpenSpec 的 `claude own-files` 属跨平台兼容必需，勿强改软链。
- **Magpie 同步机制**：改 `~/.config/magpie/library/skills/*/SKILL.md` 后执行 `magpie library sync` 即可分发至全端（Magpie 会保留本地修改不被自动更新覆盖）；停用某个全局技能优先用 `magpie library skill agents <name> none` 保留源码可逆恢复。

## 三、下次模型升级一键复跑提示词

```text
模型刚升级了，请按 docs/context-pruning-playbook.md 的六步闭环，重新帮我盘点并精简当前项目的 Agent 上下文和本机已安装的 Skills：
1. 先只读盘点每轮必载面与按需加载面（字数、字节数、上下文单元）并解析各客户端真实会话调用记录（禁裸 grep 技能名）；
2. 用「新模型在删掉这句话后行为会不会变」的标准重新审视旧规则，按修、删、挪、改写、保留做成逐段清单交我确认，确认前不改任何文件；
3. 我确认后按「先整行搬迁 → 再压缩 → 机械自检与消失行对账 → 独立子代理盲审 → 埋暗号正反对照实测」跑完闭环。
```
