## 2. 实施顺序与任务

所有任务均未开始。文件路径是建议接点，可按既有六大领域内聚调整；不为保持表格结构制造空包装。

### 任务 1：工作区身份

- 明确 workspaceRoot、executionCwd、projectKey、workspaceId 和构造验证；定义 rootDir 显式别名的兼容/冲突。
- CLI 捕获启动目录，Session/Manager/ContextManager/摘要路径移除 cwd 和 '.' 隐式回退，副作用前拒绝缺参。
- 复用 native 项目身份算法，覆盖 Windows 短路径和大小写。
- 证据：新旧显式参数兼容、缺参数/相对根拒绝、两工作区身份稳定；不把全局缓存直接当成已有越权证据。

### 任务 2：沙箱、执行与写租约

- 会话持有 PathSandbox，ToolContext 明确根/执行目录；文件工具和 ShellScope 使用一致身份。
- 共享工作区写租约覆盖父子文件工具、Shell 及声明写能力的外部调用，定义取消和清理后释放。
- 扩展 scripts/check-core-boundary.ts，沿用 pnpm check-architecture 与既有 Headless 规则。
- 证据：并发同名文件/不同 cwd、符号链接越界、脚本身份变动及实例销毁隔离；不宣称任意 Shell 具有 OS 沙箱。

### 任务 3：ChildGrant 与角色

- 有效父授权快照包含模式/规则/能力/工具/技能/工作区/剩余限额，逐轴求交。
- 角色预设单一真源；白名单省略/空集合/非法工具及模型覆盖行为明确。
- 保持 Plan 拒绝 spawn，只读角色移除通用 Shell；隐藏工具伪造和再注册不得扩权。
- 证据：祖先 deny/ask、模式、空名单、绑定失败、即时撤销和审批缓存隔离。完成本任务后才可交付委派入口。

### 任务 4：v2 日志与 v1 升级

- SessionStore 明确 v2 Envelope、seq/prevRecordId 与 parentId，以及分支/全局控制事件。
- SessionManager 调整目录发现、sidecar 版本与物理增量校验；缓存可丢弃重建。
- v1 浏览只读，取得源锁后生成 v2 副本，保留原件；Header 保存 upgradeIdentity 和别名来源。
- 独占临时文件/fsync/源复核/独占安装/目录同步，来源变化拒绝自动合并。
- 证据：格式兼容、重入、安装崩溃、源变化、坏引用和缓存丢失；旧读者拒绝 v2 的边界进入迁移说明。

### 任务 5：持久分支与投影

- branch 创建、selectBranch 选择和追加进入同一队列，耐久成功才更新对外游标。
- 初始根或闭合完整交互才可分叉，忙碌会话/共享写任务阻止切换。
- 分开三种 revision，切换同步恢复 history、ContextManager、reset、repair、checkpoint、剪裁。
- 证据：切换后无新消息立即重启仍正确；两分支状态不串用，坏引用不静默截短，半事务分叉被拒绝。

### 任务 6：摘要与独立导出

- branchWithSummary 明确原叶子/目标/共同祖先，失败不移动游标，usage 正常入账。
- forkSession 提取有效路径并映射引用，不复制审批/任务/收件箱；导入 usage 不重复计费。
- 证据：摘要范围、取消、导出原子安装、状态/协议适用性及源文件不变；提示分叉不回滚工作区。

### 任务 7：运行时与启动事务

- AgentRuntime 管理任务树，标准 AgentSession 执行，状态机以技术设计 §7.1 为准；子主轮结束但后代未结束时进入 waiting_children，继续占槽/计期限，不提前写终态。
- 启动幂等键、容量守卫与耐久来源，子 Store/目录/取消控制器独立，默认新上下文。
- Session 内部事务提交确认后激活后台；未受理不执行子模型或副作用。
- spawn_agent 自管超时、取消先清理再闭合；不把所有工具全局改成并行。
- 证据：准备失败、受理前取消、父写失败、多工具部分成功及回执/激活间崩溃；孙任务清理/子收口完成后才发子完成通知，无孤儿启动或半闭合历史。

### 任务 8：可靠通知

- 子终态与可重建 outbox 耐久保存；eventId 至少一次投递，父唯一写者收件后 ACK。
- MessageStore.append 保存带来源/deliveryId 的消费消息，确认可补齐，重投不重复注入。
- 绑定父会话/分支/原调用，仅在安全边界消费；不得插入 canonical 工具事务中间。
- 证据：终态/outbox、收件/ACK、消息/确认各故障窗口，未知不补成功，不追加第二个启动结果。

### 任务 9：生命周期与唤醒

- SessionCoordinator 互斥调度用户任务和通知；CLI 同分支空闲默认唤醒，SDK 默认只通知。
- 当前 run 只消费相同 rootTaskId 的通知；旧任务通知等待父空闲后的独立轮次。子协调器必须在原预算内处理后代结果并收口，不受 SDK 根会话默认不唤醒的设置影响。
- 分清正常父轮结束、Ctrl+C、本轮子树、切会话、reset、oneshot 与 Runtime.close。
- 独立事件总线、保留旧会话句柄，通知不进入新会话/其它分支。
- 重启只对账和补发，不重放模型/工具；缺失结果沿用 OUTCOME_UNKNOWN。
- 证据：父返回子继续、waiting_children 到期取消后代、用户输入/旧任务通知隔离、异分支完成、切会话、退出清理、无事件不空转；清理后才放锁。

### 任务 10：限额、账本与宿主资源

- 原子预留容量/共享预算，默认以技术设计 §6.6 为准；满额拒绝，不加隐式持槽启动队列。
- 请求身份去重，own/descendant/summary 分开，未知 coverage 不计零；后代与通知共用 rootTaskId。
- 可取消 FIFO 冒泡审批，子缓存隔离，等待继续计期限。
- 模型侧四个工具走正常 agent:spawn 权限门与成员检查，Plan 不绕过；显式 CLI 管理操作经宿主 API 审计，模式收紧后用户仍可取消旧任务。
- MCP 受限代理和引用计数，保留 source/generation/epoch/digest 和父撤销；worktree 不自动继承 Stdio 授权。
- 证据：抢最后槽、递归/宽度/累计、孙级去重、预算并发预留、审批正确关联、子销毁不关父连接和目录撤销。

### 任务 11：worktree 适配器

- 宿主 WorkspaceIsolation 与派生授权，Git 权限独立、物理身份登记，不从 spawn 推导。
- 本版记录提交作基线，脏工作区拒绝；不自动 commit/stash/复制秘密。
- 检查 tracked/staged/untracked、二进制及新提交；有变化/检查失败保留，只自动回收自身且确认干净的工作树。
- 证据：脏基线、产物保留、路径身份复核、进程先退出、检查失败不强删；不自动合并/强删分支。

### 任务 12：目录、全文与归档

- CrossProjectSessionCatalog 独立，全局目录用有效 sidecar，缺失流式重建；默认排除归档/内部子会话。
- 搜索完整 user/assistant 可见文本与分支摘要，返回来源及可续答边界；语法以技术设计 §5.1 为准。
- 限制单行/查询/并发/结果/期限，正则 worker 可终止；取消关句柄，覆盖不足返回 partial。
- archive_state 耐久追加，不搬文件；有运行/子任务/待消费通知时拒绝。
- 证据：正文末尾独有词、中文和跨块召回、病态正则、删缓存归档仍在；读历史不获得跨项目执行信任。

### 任务 13：CLI 整合

- 注册四个子工具和 /agents，扩展 history/branch/fork/archive；命令/工具成员边界一致。
- 带来源展示进度与通知，复用 Ctrl+O，不承诺撤回已输出终端内容；非 TTY 稳定摘要。
- 协调审批、输入与唤醒，秘密输入缓冲后台展示；配置/密钥复用现有入口。
- 证据：REPL/oneshot/非 TTY、通知收集提示、并发审批、快捷键及用户输入竞争回归。

### 任务 14：整体验收与文档

- 汇总技术设计 §9，运行全量门禁、构建和 Windows/POSIX 真实进程验收。
- 正常取消和崩溃单列，清理未确认/平台跳过/usage 缺失不冒充通过。
- 固定冷热缓存和搜索基准后确定阈值。
- 证据：本计划 §4 材料齐全，迁移、使用、发布准备只描述实际完成能力。

## 4. 验证与证据

### 4.1 自动化门槛

行为以技术设计 §9 为准。扩展现有 Store、Manager、ContextManager、权限、输入、MCP、active-session 测试，新增跨组件故障用例；文件名按实际结构确定，不把未来文件名列表当成已有覆盖。

至少在以下窗口注入故障：启动回执提交前后、子终态落盘前后、outbox/ACK、父消费消息/确认、分支游标提交、v1 副本安装。断言历史、通知、账本、锁和资源结果，不只断言 Promise 完成。

### 4.2 构建与真实平台

- pnpm verify：typecheck → test → lint，含架构与密钥扫描；--verify-only 同源。
- pnpm dev:build：构建校验后不启动 REPL，验证包拓扑与 Windows junction 自愈。
- Windows/POSIX 真实多层进程：取消、超时、退出、MCP 关闭、保留工作树；未运行平台明确未验收。
- 性能：小/中/大固定数据，记录会话数/字节数、冷热状态、峰值内存、首批结果和取消耗时，不预先承诺毫秒级。
- 真实模型若另获授权，测试后台探索、父继续、通知综合与失败收口；本次不授权付费调用。
