# v0.0.6 迁移说明

v0.0.6 实现了受控 MCP (Model Context Protocol) 生态扩展，以独立公共包 `@kiturone/kapibala-mcp` 接入，维持 Headless Core 零外部运行时依赖。本版功能、本地回归与三包打包冒烟验收已完成；规划与实现阶段不修改工作区版本号，包版本保持与上一版本连续。完整使用入口见 [MCP 使用指南](../mcp.md)，技术方案设计见 [技术设计方案](../superpowers/specs/2026-10-12-v0-0-6-mcp-ecosystem-design.md)，验收证据见 [验收记录](../verification/v0.0.6.md)。

## CLI 与配置

MCP 配置为可选特性，在没有配置时 CLI 完全保持零外部网络或进程开销，不增加启动等待。

### 1. 配置文件发现与项目信任

- **配置路径**：
  - 全局配置：`~/.kapibala/mcp.json`
  - 项目配置：`<projectRoot>/.kapibala/mcp.json`（工作区真实根目录，遵循 Windows native 长路径规范化）
- **项目信任隔离**：
  - 项目级别的 MCP 配置受项目信任控制（`trustedProjects`）；未受信任的项目，其项目级 `mcp.json` 自动被排除并给出安全告警，绝不隐式加载或执行其中的服务声明。
- **宿主硬禁用**：
  - 启动时传入 `--no-mcp` 可直接切断所有 MCP 发现、初始化与会话插件挂载；即使磁盘存在配置文件，CLI 也绝不启动任何外部服务或暴露 MCP 工具。

### 2. 管理命令与交互变更

- `/mcp`：查看已配置的 MCP 服务清单、连接状态（connected / stopped / error）与各服务能力统计；
- `/mcp tools <server>`：列出指定服务已导出的工具清单及其只读安全标记；
- `/mcp reconnect <server>`：手动重连指定服务（单调递增代次，沿用当前已解析配置，不重新读取磁盘）；
- `/mcp enable <server>` / `/mcp disable <server>`：在当前会话内动态启用或禁用某个服务的工具，纯内存生效，严禁写回磁盘；在会话执行忙碌期间执行变更会被安全拦截；
- `/prompts [query]`：纯内存检索服务已就绪的 Prompt 模板元数据（绝不预取远端正文）；
- `/prompt <server>/<name> [arguments-json]`：拉取并准备 Prompt 任务文本，进入统一任务执行流（支持单条 user 消息提交、角色标签安全降级与统一取消）。

### 3. 展示与脱敏

- MCP 导出的工具在终端统一格式化为 `[MCP: serverName] toolName`，区别于内置核心工具；
- 工具调用参数中的敏感字段（包含 key、token、secret、password、credential 等子串）自动脱敏为 `[REDACTED]`，绝不在终端或日志中泄露明文。

## SDK 与持久化

### 1. 架构与依赖边界

- 核心包 `@kiturone/kapibala`（Core）维持纯粹的 Headless 架构，运行时外部依赖严格为 0；
- MCP SDK 与 `@modelcontextprotocol/client` 依赖完全封装在独立公共包 `@kiturone/kapibala-mcp`；
- Core 不得依赖 MCP 包，MCP 包不得依赖 CLI 或直接读写终端；
- 宿主通过 `createMcpPlugin(config, options)` 创建插件实例，并通过 `session.use(plugin)` 挂载到 AgentSession。

### 2. 插件所有权与生命周期

- 严格遵循「一 Session 一插件实例」约束：严禁将同一个 McpPlugin 挂载到多个会话，或在同一会话中重复挂载；
- 会话生命周期结束或切换时，插件实例自动执行 teardown，彻底回收底层进程树与网络连接句柄，禁止遗留孤儿进程。

### 3. 来源持久化与历史安全边界

- TextBlock 与 ToolResultBlock 增加可选 `mcpSource` v1 元数据（记录 serverName、toolName、generation 与 callId）；
- `mcpSource` 仅作为本地事实落盘到会话历史文件，序列化为模型请求（wire）时自动剥离，绝不向外部模型发送内部来源字段；
- 旧版本历史文件（无 `mcpSource`）可完全无缝加载兼容；
- 恢复历史会话、切换项目或续答时，仅恢复历史文本事实，绝不继承活动服务的连接、不恢复启动审批授权，也绝不隐式重放工具。

## 执行与网络安全边界

1. **非交互环境硬防线**：
   - 非 TTY 环境或无审批通道时，未预先授权的 Stdio 服务启动直接拒绝，报告 `MCP_STARTUP_UNAUTHORIZED`，绝不静默放行外部子进程启动。
2. **私网与保留网段硬拦截**：
   - HTTP 传输目标受到底层 IP 白名单与 Socket Remote IP 二次复核保护；
   - RFC 1918 私有地址、环回网段（除显式白名单 127.0.0.1 外部调试外）、CGNAT、链路本地、组播及保留网段一律拦截，严格防御 SSRF 与 DNS Rebinding 攻击。
3. **工具事务闭合不变量**：
   - MCP 工具调用遵循 Core 核心事务不变量：assistant 的 `tool_use` 进入历史后，对应的 `tool_result` 必须紧随其后；
   - 在途取消或超时时，事务必须被正规闭合为取消或未知状态后方可释放 Session 锁。
