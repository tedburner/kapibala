# v0.1.0 迁移说明（候选草稿）

当前尚未发布。最终候选版本、平台范围与安装签名须以实际发布附件及验收为准。

- 桌面复用现有 Harness，默认空间位于 `~/.kapibala/workspaces/default`；添加项目绑定已选择的物理根，名称仅为显示别名，不移动目录或历史。
- CLI 与桌面共用模型配置、信任记录及兼容的历史。原本的 CLI/SDK/MCP 仍可独立使用；Core 运行时保持零依赖，最低 Node 20；桌面自带 Electron 运行时。
- 新设置写入使用配置事务，旧版 CLI/外部编辑器不参与新锁，应避免并发修改全局配置。桌面和 CLI 无跨进程工作区写租约，勿同时向同一目录执行写任务。
- 桌面启用 `exact` 工作区历史桶策略；旧 SDK/协议调用保留已有 Git 根提升行为。公共差异仍以 sdk-compatibility.md 和 API fixtures 为准，wire 仍为 1.0。
- 协议管理的会话（local-protocol / 桌面宿主装配的父子会话）现在注入 `~/.kapibala/AGENTS.md` 作为用户级指令，并在 `~/.kapibala` 下产生日志与审计恢复目录；交互式 CLI 不传宿主目录、行为不变。不接受该注入的集成环境请改用交互入口或提供空的 `.kapibala/AGENTS.md`。
- 崩溃或清理无法确认时保留 guard，需人工确认旧工具进程已退出后显式恢复。不会自动重发未确认写操作，也不自动恢复 FullAccess。
- 卸载应保留配置与历史；各目标的实际系统卸载仍须正式候选验收。测试 DMG 的副本删除结果不能替代系统卸载证据。
