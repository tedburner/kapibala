# v0.0.9 迁移说明

- 默认直接 CLI、Core SDK 和 MCP 包入口保持兼容，仍发布三个包。
- CLI 增加 `protocol`（纯浏览器协议）与 `client`（Node 本地 RPC）子路径，不要求用户安装新的协议包。
- 不修改既有 canonical 历史格式，不从旧记录恢复审批、控制权或在途工具；daemon 重启后显式打开历史会话。
- 活动会话冻结配置；配置修改后需关闭再打开会话。未信任项目或缺密钥时先使用直接 CLI 配置，不在 daemon 中弹出向导。
- 同一 conversation 不能同时被直接 CLI 和 daemon 持有；不同 conversation 的跨进程项目写入仍需使用者避免并行。
- 宿主内会话按真实 Git 工作树根归组；从根目录或子目录打开同一 conversation 复用句柄。
- `connect -p` 退出会关闭本次打开的宿主会话句柄，历史仍保留；交互连接退出保留 idle 句柄，可用 `/close` 显式释放配额。
- Shell 审批完整展示绑定后的命令与执行位置，控制字符显示为转义；超预算或无法安全完整展示时拒绝审批。清理失败保留存储锁，成功后再释放。
- 暂不提供网络监听、GUI、系统服务安装、自动更新或守护进程崩溃后的自动任务续跑。

命令、预算与安全失败行为见 [本地宿主说明](../local-host.md)。本说明随 v0.0.9 发布生效；实际支持平台与剩余验收边界以 [验收记录](../verification/v0.0.9.md) 为准。
