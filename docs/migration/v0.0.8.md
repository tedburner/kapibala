# v0.0.8 迁移说明

实现、本地与验收于 2026-10-17 完成并随 v0.0.8 发布；包版本与 CLI_VERSION 为 0.0.8。设计基线见 [技术方案](../superpowers/specs/2026-10-17-v0-0-8-terminal-experience-design.md)，验收记录见 [验收记录](../verification/v0.0.8.md)。

## 命令输出统一结构化（CommandOutput）

1. **废弃命令直接写屏副作用**：
   在 v0.0.8 之前，CLI 的 Slash 命令实现（`packages/cli/src/commands/*`）直接调用 `console.log` 或 `process.stdout.write`。这会导致在全屏 TUI 或现代终端交互下与流式输出产生冲突、撕裂光标与状态栏。
   从 v0.0.8 起，所有命令统一改为纯数据返回结构化的 `CommandOutput`（或返回 `string` 由 `resolveCommandOutput` 自动包装）：
   ```ts
   export interface CommandOutput {
     content: string;
     title?: string;
     format?: 'markdown' | 'plain' | 'table';
     metadata?: Record<string, unknown>;
   }
   ```
   - 宿主（如 `InteractiveHost`、降级流或外部宿主）负责在合适时机与位置统一渲染；
   - 新增架构门禁 `scripts/check-cli-boundary.ts` 静态扫描，严禁在 `commands/` 目录下直接调用 `console.log`。

2. **自定义命令集成适配**：
   若下游扩展了 CLI Slash 命令处理器，其签名已统一对齐：
   ```ts
   // 旧用法：
   console.log('Done');
   return;

   // 新用法：
   return {
     content: 'Done',
     format: 'plain',
   };
   ```

## 纯展示模型子路径导出（`@kiturone/kapibala-cli/view-model`）

1. **子路径独立导出**：
   `packages/cli/package.json` 现已正式增加 `./view-model` 导出切面：
   ```json
   "./view-model": {
     "types": "./dist/view-model/index.d.ts",
     "import": "./dist/view-model/index.js",
     "default": "./dist/view-model/index.js"
   }
   ```
   该模块导出的 `TerminalViewModel`、`terminalViewReducer` 与相关选择器（如带 WeakMap 缓存的 `selectMessages`）严格保证 **零 Node.js 内置依赖**（不依赖 `node:fs`、`node:process`、`node:path` 等），由 `scripts/check-view-model.ts` 门禁约束，可直接在 Electron 渲染进程、浏览器环境与 WebWorker 中安全复用。

2. **快照缓存行为**：
   `selectMessages` 针对 `TerminalViewModel` 实例启用快照级 `WeakMap` 缓存。下游如果自定义扩展了 State 并期望触发重选，必须遵守 Redux 风格的不可变更新原则（不可变更新 `state.messages` 引用），原地 mutation 将命中旧缓存。

## 终端模式守卫与输入流管理

1. **双重异常恢复与生命周期保护**：
   终端交互由 `TerminalModeGuard` 统一接管：
   - 监听未捕获异常与进程中断，保证在任何退出路径上自动关闭备用屏幕、恢复光标与恢复原始 TTY rawMode；
   - 采用 `TerminalInputStream` 保证 stdin 单读者，杜绝多处读流争抢。
2. **CSI-u 与粘贴隔离适配**：
   `TerminalInputFramer` 默认启用 40ms 拼包缓冲和 Bracketed Paste 拦截：
   - Windows ConPTY 下的键盘修饰键（Shift/Alt/Ctrl）分片序列不再被误拆为独立按键；
   - 粘贴内容（默认上限 1MiB）不再自动作为回车指令触发执行。

## Core 运行时观察者（subscribeTaskChanges）

`AgentRuntime` 新增只读的 `subscribeTaskChanges` 观察订阅方法：
```ts
const unsubscribe = runtime.subscribeTaskChanges((task) => {
  // task 包含只读任务元数据、状态变迁与错误原因
});
```
该订阅仅作为轻量级观察通道，不阻断任务状态机，不引入并发锁竞争。CLI 宿主利用此通道驱动底栏的实时子任务进度展示。
