# v0.1.5 迁移说明

> 状态：随 v0.1.5 分支开发维护。发布说明见 [v0.1.5 发布说明](../releases/v0.1.5.md)，与 [SDK 兼容性盘点](../sdk-compatibility.md) 同口径。

## 1. 本地 Wire 保持协议版本 2（非破坏性扩展）

v0.1.5 遵守整数协议代际规则（非破坏性变更不升版本号）：

- `PROTOCOL_VERSION` 保持整数 `2` 不变；
- `SERVER_CAPABILITIES` 新增 `'external-session'`，承载 16 个 `external/*` 方法与 `external/event` 通知；
- **兼容表现**：不声明 `'external-session'` 的 v0.1.4 客户端连接 v0.1.5 宿主可正常握手并运行本地会话，服务端不会向其下发 `external/event`；未在握手中声明 `'external-session'` 即调用 `external/*` 方法将返回 `PROTOCOL_MISMATCH`。
- 若客户端自定义消费 `WireNotification` 联合类型，升级类型声明后新增 `{ method: 'external/event', params: ExternalWireEvent }` 分支；通过 `LocalClient.subscribeExternal(listener)` 可独立订阅该事件流。

## 2. Core 兼容细节与外部状态目录隔离

- `@kiturone/kapibala`（Core）与 `@kiturone/kapibala-mcp` **无破坏性公共导出变更**（Core 包含内置 `grep` 工具可选 `include` 通配符过滤与流式限额加固、`PathSandbox` Windows `realpathSync.native` 物理路径归一、会话启动 `recoverIncompleteAudits` 默认静默回收不写 stderr、默认会话最大轮次预算调优等内部兼容改进）。
- 13 项内置外部代理预设（Claude Code、Codex、Pi Coding Agent、Antigravity、OpenCode、DeepSeek Harness、Gemini CLI、Qwen Code、Oh My Pi、Qoder、Qoder CN、TRAE、TRAE CN）默认采用**按本机安装状态自动启停**：未在系统 `PATH` 或已知常见安装目录检测到可执行程序的预设默认保持 `enabled: false`，用户在设置页或 `/external harness enable <id>` 手动切换后以磁盘覆写为准。
- 外部代理配置、会话登记簿与只读展示快照完全隔离在 `~/.kapibala/external/`（目录权限 `0700`、文件权限 `0600`），不写入 Core 会话 JSONL，也不参与本地上下文压缩或 `/delegate` 子代理树：
  - `harnesses.json`：仅保存内置代理的增量覆写（`overrides`）与自定义 `Local ACP Command` 条目（`custom`），内置预设本体不物化落盘，支持一键恢复默认；
  - `sessions.json`：保留最近最多 50 条外部会话元数据（满额新增时优先自动淘汰最旧已终态记录及其快照，绝不静默淘汰活跃项）；
  - `snapshots/<sha256(id)>.json`：结算与关闭时原子写入脱敏只读展示快照（硬上限 160 条消息且不超过 680 KiB，留足 1 MiB 单帧安全余量）。

## 3. 凭据安全与无 Shell 启动边界

- **禁止明文密钥落盘**：外部代理复用对应 CLI 自有登录态（如 `claude auth login`、`codex login`、`pi /login`、`agy acp --login`）；如需透传环境变量，`harnesses.json` 的 `envFrom` 字段**只记录环境变量名**（如 `DEEPSEEK_API_KEY`），严禁写入密钥值。
- **全程 `shell: false`**：外部进程统一经数组参数直接系统调用启动，拒绝包含路径分隔符的相对路径命令；Windows 下按 `[".exe", ".cmd"]` 优先级解析并静态解包标准 npm/pnpm `.cmd` 垫片（`.exe` 二进制、`.js` 脚本与 `#!...node` shebang 三形态），任意自定义批处理脚本返回 `EXTERNAL_UNSUPPORTED_SHIM`。
- **子进程环境白名单**：外部子进程仅继承基础系统运行与代理变量及显式 `envFrom` 白名单，自动剥离相对 `PATH` 段、`NODE_OPTIONS`、`ELECTRON_RUN_AS_NODE` 与动态库预加载变量。

## 4. 只读历史归档与可恢复门禁解耦

- 外部子进程在空闲 30 分钟回收或应用重启后，打开历史外部会话会立即从 `snapshots/` 加载只读展示快照，不会出现空白页。
- 仅当外部会话满足持久身份门禁（`resumable === true`，如 Claude Code `--resume`、Codex `thread/resume`、Pi `--session-id`、OpenCode `session/load`、DSH `session/resume`）**且**当前代理启动配置摘要（`configDigest`）未发生变更时，才允许原地发送新轮次自动拉起恢复；否则输入框固定为只读归档态，需新建外部会话继续。

## 5. 跨信任域权限与并发约束

- 工作区必须先通过项目信任（`isProjectTrusted`），未信任工作区调用 `external/*` 会话或目录内探测一律拒绝（`TRUST_REQUIRED`）。
- Kapibala 本地的 `Auto` / `FullAccess` 档位**绝不跨信任域自动批准外部代理的审批请求**；外部审批超时（120s）或断连一律按拒绝/取消收口。
- ACP 客户端能力固定声明 `fs: { readTextFile: false, writeTextFile: false }, terminal: false`，对端发起的 `fs/*`、`terminal/*`、`elicitation/*` 请求一律返回 `-32601 Method not found`。
- 并发上限：单宿主最多同时存活 **4** 个外部子进程，同一工作区同一时刻最多 **1** 个运行中外部会话（同工作区外部代理与本地会话并存时不共享写租约，桌面顶部横幅会给出并发改动提醒；Git Worktree 物理隔离排入 v0.1.6）。
